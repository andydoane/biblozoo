## How to maintain this roadmap

- On every future fix PR, tick its planning ID by updating this file with **actual PR number/link**, merged integration commit, `NOT TESTED / FAIL / PASS` evidence, and any newly discovered regression. Update `docs/PROJECT-HANDOFF.md` and `docs/TESTING.md` **in the same PR**; never simply mark “done” because CI is green.
- If one root cause genuinely spans adjacent planned PRs, re-scope with the owner before combining. If new information points to an existing fix, mark the issue as retest-required, do not silently delete it.
- This roadmap is **proposed ordering**, not a commitment to any fixed number of PRs, an automatic CI/release workflow or implicit authorization to install/merge.

**Starting recommendation:** R01 (Flashcards UI pop restoration after mic capture), because it disables sound in the **entire app** until recovery. Before any implementation, preserve an iPhone repro, ensure the production-family backup is privately retained, and plan targeted post-fix hardware retest.
