## Decision and ordering principles

1. **Safety first:** keep the original 10-profile production app and its private family-v2 export separate from the 11-profile Audio Test app/export; no backup JSON, Zookeeper IDs, children's voice recordings or personal progress in commits, screenshots, PR descriptions or diagnostic telemetry. Do not uninstall/reset/import on either phone app; request explicit owner approval before another production-bundle-ID installation on the original iPhone.
2. **One observable behavioral responsibility per PR** when feasible. A PR may group two bugs *only* when they share a tightly defined component (e.g. the two Flashcards external-media playback contexts; the two animated Read scenes), but must test both separately. Prefer smallest Swift changes that preserve the established user-tap-only session activation and explicit Welcome Back recovery.
3. **CI plus phone acceptance:** every PR needs focused Node/source tests, all existing CI jobs (including web build and Swift parse/packaging checks), updated handoff/TESTING doc, and an explicit physical-iPhone repro/retest result before closing its issue. Node/Web PASS is not proof of audible sound, view timing or data preservation. Owner can batch *observational* testing across multiple PRs; do not assume any unreported check is PASS.
4. **Interruption invariant:** when held in App Switcher/locked or another app takes sound, affected clocks and visuals stop, no stale timer, audio, pet/reward or score advances; user must explicitly tap the proper Welcome Back/Retry before resuming (no automatic competing-app audio takeover). A plain in-app menu Close is not an OS interruption and should not create an unnecessary overlay.
5. **Web/PWA and Android must not regress** as iOS native work changes. Preserve background/route policies, Daily To-Do token isolation, recorder permission/privacy, onboarding, all four Feeding modes, all 12 Practice games, five Playground activities and all eight Read activities. Keep post-#124 PWA icon cache versioning independent of obsolete patch names.
6. **Do not arbitrarily fix Silent Mode first.** Changing `AVAudioSession`'s category is a cross-cutting policy migration that can invalidate all the interruption work; choose the product policy early, but land/test its implementation **after** stabilizing session ownership and external media.
